Customers now has Export CSV and Export JSON actions. Downloads include all search matches, independently of list pagination. Server output uses an explicit whitelist: customer ID, username, first/last name, email, phone, city, country, registration date, active flag, order count and total spent. CSV protects formula-like cells and supports Bengali UTF-8. Responses stream in bounded database chunks with private/no-store headers. Passwords, tokens, addresses, login/device/IP metadata and account internals are excluded. Both export and the existing customer list now enforce the canonical platform-staff permission; customer and tenant-subaccount access are rejected.
